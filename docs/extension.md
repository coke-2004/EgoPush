# 扩展一个形状或本体

## 更换形状

复制 `arrangement/shapes/nyu.json`，为每个槽位填写唯一名字和中心横纵坐标，单位为米。所有槽位共享一组水平轴。当前入口支持 3–20 个槽位，初始化器生成同样数量的散箱。运行示例：

```bash
python -m arrangement runs/new-shape 10001 --shape my_shape.json
```

槽位须留出 26 cm 方箱和机器人可进出的空间。过密的笔画、跨度过大的字形或缺少参照的长距离转移可能无法完成。NYU 的成功率只适用于报告里的 20 箱布局；新形状需要独立测试。评估允许整个形状平移、旋转以及同色箱子交换，不允许缩放或镜像。

## 更换机器人

入口接受 `--robot 模块名:类名`。用现有 RBY1 适配器作样例，把模型、材质和动作放在独立目录。适配器用种子与方箱数初始化，并提供以下数据和操作。

| 模块 | 接口与约定 |
|---|---|
| 运动 | `tip` 是水平抓取点相对底盘的位置。底盘坐标为前向 +x、左向 +y。实现 `drive(v,seconds)`、`turn(rate)`、`stop()`、`look(pan,pitch)`、`grip()`、`release()`。 |
| 相机 | 将相机映射到巡查四向、低位左前/右前/后方、头部和近摄这些逻辑角色。`observation` 返回 RGB 和光轴深度，`geometry` 返回相机在底盘系的位置和旋转，`visible` 返回当前可见箱心。识别代码使用相机视场角及传感器索引。 |
| 记录与评估 | 当前运行器针对 MuJoCo，使用模型、数据、渲染器、`box_addresses`、`step` 和 `frame_hook` 保存轨迹。外部录像跟踪名为 base 的车身。 |
| 机械几何 | 同时复核规划器的底盘与持物包络、相机的可见高度和对正容差、手部抓取轨迹。仅换 XML 无法保证安全通行或抓住物体。 |

保持已知箱群的相对几何、局部观测、决策和独立评分之间的数据流清楚。新增本体先验证相机投影、实际轮驱和单箱抓放，再做多箱新种子测试。已验证的本体和形状组合为 RBY1 / WUJI2 与 NYU。
